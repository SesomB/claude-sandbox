# claude-sandbox

A sandbox repository for experiments.

## Contents

- **[Hermes Agent, air-gapped](docs/hermes-airgap/README.md)**: offline deployment of Nous Research Hermes Agent v0.22.2 on a Debian 13 server, with per-user backends that Hermes Desktop reaches from Windows 11 workstations over SSH tunnels. Includes the bundle builder, installer, user management, firewall, the Windows scripts and an offline end-to-end test.
